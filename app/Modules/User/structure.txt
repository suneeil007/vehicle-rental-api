Yes. Since you're building a production-quality Vehicle Rental API, I would not put User management inside the Auth module.

The separation should be:

Auth Module → Register, Login, Logout, Refresh Token, Change Password, Forgot Password
User Module → User CRUD, Profile, Roles, Branch Assignment, Status, User Listing
