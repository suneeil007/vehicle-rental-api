Custom modular Artisan command
****************************************

php artisan module:make Vehicle  => this command to generate the module folders and files with 
php artisan module:make-migration Vehicle create_vehicle_categories_table => this for migrations



app/Modules/Vehicle/
├── Controllers/     → Handles HTTP (request in, response out)
├── Requests/        → Validates incoming data
├── Services/        → Business logic / orchestration
├── Repositories/    → Data access (talks to the database)
├── Models/          → Represents DB tables (Eloquent)
├── Resources/       → Shapes the JSON output
├── Providers/       → Wires everything together (the "glue")
├── Database/        → Migrations (schema)
├── routes/          → URL → Controller method mapping
└── config/, Helpers/ → Module-specific config/utilities
